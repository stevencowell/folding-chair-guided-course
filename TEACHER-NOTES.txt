FOLDING CHAIR GUIDED COURSE — TEACHER NOTES

COURSE DESIGN
The ten modules use mastery-oriented questioning. An incorrect multiple-choice choice triggers feedback aimed at the specific misconception, then a stronger clue after repeated attempts. Written models stay locked until a genuine attempt has been made. The webpage does not transmit or verify marks; a saved PDF is student evidence, not an automatically authenticated test record.

SUGGESTED CLASSROOM ROUTINE
1. Teach or read the theory and inspect the linked diagrams during the first lesson of the paired-week block.
2. Use selected guided questions for discussion, then have students complete the set individually.
3. Require written responses to be the student’s own first attempt before model comparison.
4. Ask students to improve weak wording after feedback and self-assess honestly.
5. At the end of the block, students enter their name and class and use Print / Save PDF for Google Classroom.

TECHNICAL AND RECORD-KEEPING NOTES
- Answers are stored only in the browser using local storage. They can be lost when browser data are cleared, another device is used or a different extracted folder is opened.
- The PDF workflow is deliberately transparent: it creates a visible record students can submit, but it is not a secure examination system.
- Reset clears that module’s student details and responses from the current browser only.
- All pages work locally after extraction; no web server, Apps Script or external account is required.
