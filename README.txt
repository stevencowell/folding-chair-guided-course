FOLDING CHAIR GUIDED COURSE — COMPLETE TWENTY-WEEK WEBSITE

START HERE
1. Extract the complete ZIP file.
2. Open index.html in the top-level folder.
3. Keep the folder structure intact. The pages rely on the included styles, scripts, plans and images.

COURSE STRUCTURE
The landing page links to ten complete paired-week modules:
- Weeks 1–2: Brief, safety, design and mark-out
- Weeks 3–4: Timber preparation and joinery foundations
- Weeks 5–6: Bandsaw shaping and joinery refinement
- Weeks 7–8: Drilling, countersinking and dry assembly
- Weeks 9–10: Design features and technical drawing
- Weeks 11–12: Assembly, adhesives and project planning
- Weeks 13–14: Surface preparation and finishing
- Weeks 15–16: Chemical safety and sustainability
- Weeks 17–18: Portfolio, evaluation and revision
- Weeks 19–20: Final quality, submission and reflection

ASSESSMENT AND OUTCOMES
- Practical – 20%
- Theory – 10% (folio and written tasks)
- Syllabus outcomes IND5-1 to IND5-10 are retained on the landing page.

EACH MODULE INCLUDES
- Detailed textbook-style theory connected to the folding-chair project
- Relevant chair plans, technical diagrams and workshop/tool imagery
- 12 guided multiple-choice questions
- Specific feedback for every answer option
- Progressive hints and unlimited retry-to-mastery
- Four scaffolded written responses
- Live word count and key-concept prompts
- Model responses locked until a genuine attempt is made
- Student self-assessment
- Temporary browser saving and Print / Save PDF

STUDENT WORK AND RELIABILITY
- The webpage does not send marks, answers or personal details anywhere.
- There is no Apps Script, online mark transmission or text-to-speech control.
- Answers are temporarily stored in the current browser using local storage.
- Students should use Print / Save PDF before leaving each module.
- Clearing browser data, changing devices or opening another copy of the folder can remove temporary saved answers.

PROJECT RESOURCES
- Folding-Chair-Project-Plans.pdf contains the supplied four-page drawing set.
- resources/SDS-Turpentine-Example.pdf is included as a chemical-safety reading resource.
- TEACHER-NOTES.txt contains the complete multiple-choice answer key and written-response focus for all ten modules.

TECHNICAL NOTE
The site uses local HTML, CSS, JavaScript, images and PDFs. It works by opening index.html directly after extraction and does not require a local server.
